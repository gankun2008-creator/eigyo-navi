# 概要
  これは佐賀県の某キャンプ場で繰り広げられる(予定)の死闘における武器の試作コンペ品である。

# 使用言語
  typeScript

# まじめな概要

  ## 仕様
    公開されている企業情報や契約している企業が登録した情報からAIを用いて
    ・何を提案するべきか  
    ・何台販売できていくら収益を獲得できるかの予想  
    を提案理由と共に教えてくれる
  
  ## だれが払うのか
    営業部門を持つ企業
  
  ## 支払い
    サブスクリプション方式で月10万
    
  ## なぜ毎月支払いを続けるのか
    新規取引先拡大
  
  ## 収益の具体的な数字
    1000社契約できたとして....  
    月収益=1000(社)*10万(円)=1億(円)
